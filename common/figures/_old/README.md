# 쓰이지 않는 옛 그림 보관함

여기 있는 파일은 **지우지 않고 옮겨만 둔 것**입니다.

## 왜 옮겼는가

`make_figures.m` 이 만들지도 않고, 강의노트·숙제·스크립트·CTMS 한글판
어디에서도 참조하지 않는 그림입니다. 자료를 만드는 과정에서 남은 것들입니다.

`common/figures/` 에 그대로 두면 다음 문제가 생깁니다.

- 어떤 그림이 살아 있는 것인지 한눈에 안 보인다
- 폴더를 통째로 지우고 `make_figures()` 로 다시 만들었을 때
  **되살아나지 않는 파일**이 섞여 있어, 나중에 참조를 걸면 조용히 깨진다

## 되살리려면

파일을 `common/figures/` 로 옮기고, 참조하는 곳에 그림 블록을 넣으십시오.
다만 **코드로 다시 만들 수 없는 그림**이므로, 가능하면
`make_figures.m` 에 그리는 함수를 새로 만드는 쪽을 권합니다.
강의노트의 모든 그림은 "다시 만드는 명령"이 붙어 있어야 한다는 것이 이 자료의 규칙입니다.
